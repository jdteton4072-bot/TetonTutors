# TetonTutors
Tutor application for students and mentors

## Repository layout

| Path | Contents |
|---|---|
| [`artifacts/`](./artifacts/) | Durable working documents — creative briefs, prompt packs, decision records |
| [`.claude/skills/`](./.claude/skills/) | Project skills available to Claude Code |

## Creative briefs

Planning a video, image set, game experience, or launch campaign? Run `/creative-brief`.
It interviews you through the brief questions, writes the brief to
`artifacts/creative-briefs/`, and derives a pack of generation prompts ready to hand to
Claude Code or an AI image/video tool. See
[`artifacts/creative-briefs/README.md`](./artifacts/creative-briefs/README.md).
